# Ocellus Safe Tile Trainer

Browser trainer for Ocellus's portal phase in OSRS. You get to the 2×2 safe zone where the two orange portal lanes cross before the purple waves fire, then take the orange floor portal to the next quadrant.

Play: https://gronuj.github.io/ocellus-trainer/

Movement follows OSRS rules: 600 ms ticks, run is 2 tiles per tick, diagonals first, clicks apply on the next tick. Timings can be changed in the bottom bar.
